# Lab 3: Convolutional Neural Network (CNN) for Image Classification

## Overview
This experiment involves building and training a Convolutional Neural Network (CNN) using TensorFlow and Keras to classify images from the CIFAR-10 dataset.

## Dataset
**CIFAR-10**
The dataset consists of 60,000 32x32 color images in 10 classes, with 6,000 images per class. There are 50,000 training images and 10,000 test images.

## Contents
* `DL_Lab_3.ipynb`: The Jupyter Notebook containing the implementation of the CNN.
* `sample_images.eps`: Generated output plots from the experiment.
